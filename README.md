# 🔐 WinRAR Numara Şifre Çözücü (Numeric Password Cracker)

Bu basit Batch (`.bat`) betiği, şifresi unutulmuş WinRAR arşivlerinin sadece **sayılardan (0-9)** oluşan şifrelerini Kaba Kuvvet (Brute-Force) yöntemiyle deneme-yanılma yaparak bulmak için tasarlanmıştır.

## 🚀 Kullanım
1. Depodaki `.bat` dosyasını bilgisayarınıza indirin.
2. Dosyaya çift tıklayarak çalıştırın.
3. Açılan siyah ekranda şifresini bulmak istediğiniz `.rar` dosyasının adını (örneğin: `dosya.rar`) ve bulunduğu klasör yolunu (örneğin: `C:\Users\Admin\Desktop`) girin.
4. Program doğru şifreyi bulana kadar tüm olasılıkları çok hızlı bir şekilde otomatik deneyecektir.

*(Not: Bu betiğin çalışabilmesi için bilgisayarınızda WinRAR programının yüklü olması gerekmektedir.)*
